# GeoHint 2.2 — 지층 추론 수행평가 플러그인 (Paper 26.3)

부산과학고 지구과학실험 · 상대연령과 절대연령 활동 수업용 마인크래프트 플러그인.
팀마다 지층 모형(32×32×60)을 캐면서 시료를 모으고, 방사성 동위원소 힌트와 표준화석으로
8개 암석의 순서와 연대를 추론해 답안지를 제출한다.

> ⚠️ **이 저장소는 비공개(Private)로 두세요.** 코드 안에 정답 연대가 들어 있습니다.

---

## 1. 빌드 (GitHub Actions)

1. 이 폴더(`geohint-plugin`) 전체를 GitHub 저장소에 올린다. `.github` 폴더도 꼭 같이.
2. 저장소의 **Actions** 탭에서 빌드가 끝나길 기다린다 (1~2분).
3. 초록 ✓ → 실행 기록 → 맨 아래 **Artifacts** 의 `geohint-plugin-jar` 를 받는다 (zip 안에 jar).
4. 빨간 ✗ → 로그의 에러 줄을 복사해서 Claude 에게 보내면 고쳐 준다.

빌드 환경: 자바 25, `paper-api 26.3.build.244-stable`.
Paper 버전 번호를 못 찾는다는 오류가 나면 `pom.xml` 의 `<paper.version>` 을
[mvnrepository](https://mvnrepository.com/artifact/io.papermc.paper/paper-api) 에 있는 26.3 최신 stable 번호로 바꾼다.

## 2. 서버 준비

1. Paper 26.3 서버에 `geohint-2.2.0.jar` 와 WorldEdit 를 넣고 켠다.
2. `geology_section_v2.schem` 을 `plugins/WorldEdit/schematics/` 에 넣는다.
3. 팀 수만큼 모형을 붙인다. 붙일 자리에 서서 `//schem load geology_section_v2` → `//paste`.
   - 붙이는 순간 서 있던 발밑 블록이 모형의 원점(0,0,0)이 된다. 모형끼리 최소 40칸 이상 떨어뜨린다.
4. 각 모형 바로 옆에 서서 `/geo setregion <팀번호> <색>` (예: `/geo setregion 1 red`).
   - 근처의 원점 마커(강화 심층암)를 자동으로 찾아 등록하고, 모형 위에 팀 색 발광 기둥을 세운다.
   - 색 : red, gold, yellow, green, aqua, blue, light_purple, white …
5. (선택) `/geo wall all` 로 모형 네 옆면을 벽(매끄러운 돌)으로 가린다. 단면이 밖에서 안 보이게 되고,
   학생은 벽을 캐고 들어간다(벽은 시료가 안 나온다). 없애려면 `/geo wall all remove`.
6. `/geo list` 로 등록 상태와 원점 좌표를 확인한다 (커맨드 블록 TP 좌표 잡을 때 사용).

**관리자** : OP 가 관리자다 (`/op <닉네임>`).

플러그인이 알아서 하는 것 : 비·몹 스폰 차단, PvP·폭죽 피해 차단, 접속/퇴장·업적·사망 메시지 숨김,
야간투시(감마 대체) 상시 적용, 탐사 중 시간을 낮으로 고정.

## 3. 진행

| 단계 | 하는 일 |
|---|---|
| 대기 | 학생 접속 → `/team <1-5>` (크리에이티브 대기, 캐기·인벤토리 잠김) |
| 시작 | 선생님 `/start` → 3·2·1 → 서바이벌, 곡괭이·화석 나침반 4개·조사 노트 지급, 점프 강화 II, 30분 타이머 |
| 종료 | 시간 종료 또는 `/stop` → 작성 중인 답안 자동 채점(무료) → 최종 순위 발표 |
| 초기화 | `/reset` → 캔 블록 전부 복구, 진행도·인벤토리 초기화 |

## 4. 학생 조작법

**캐기** — 모형 안에서만, 다이아 곡괭이 효율 II(파괴불가).
한 번에 바라보는 면 2×2(사람 키만 한 굴), **웅크리면 1칸**. 시료는 클릭한 칸 하나만 나온다.
변성암(혼펠스·대리암·규암)과 흙은 캘 수 있지만 시료가 안 나온다.

**힌트 `/hint`** — 팀당 5회. "분석할 시료를 손에 들고 우클릭" → 그 시료 30개 소모 →
구성원소 · 반감기가 화면 중앙에, 모원소/자원소 비율이 핫바 위 한 줄에 뜬다.
결과는 야외 조사 노트(책)에 자동으로 기록되어 언제든 다시 볼 수 있다.
퇴적암에 쓰면 근원암의 연대가 나온다 (화면·소리는 화성암과 똑같다).

**화석** — 화석 나침반 ①~④ 가 각 화석을 가리킨다 (① 이 가장 얕고 ④ 가 가장 깊다).
나침반을 클릭해도 아무 일도 일어나지 않는다 (WorldEdit 의 나침반 순간이동도 막아 둠). 화석(로드스톤)을 우클릭하면 종 이름과 분류가
나오고 조사 노트에 기록된다. 연대는 학습지의 화석 연대 대조표에서 찾는다.

**답안 `/answer`**
- ① 가장 오래된 암석 → ⑧ 가장 젊은 암석. 인벤토리에서 시료를 집어 칸을 클릭하면 놓인다.
- 칸 좌클릭 → 채팅으로 연대 입력 (숫자 1개, 범위라면 숫자 2개 `331 346.7`), `취소` 로 취소. 칸 우클릭 → 비우기.
- 8칸 + 연대를 다 채우면 제출 → 채점 중… → 결과는… → 8칸 결과를 한꺼번에 공개.
  - 🟩 초록 : 암석·연대 모두 맞음 → 확정(잠김)
  - 🟨 노랑 : 그 자리 암석은 맞는데 연대가 틀림
  - 🟥 빨강 : 그 자리 암석이 아님
- 제출 횟수 무제한, 제출 간격 5초.
- 비용 : 초록 칸 무료(고정) · 같은 암석 그대로인 노랑 칸 무료 · 나머지 칸은 그 칸 시료 **10개씩**.

**점수판** — 팀별 최근 결과 8칸 색과 제출 횟수, 완료 팀은 기록 시간. 내 팀 앞에 ▶.
순위 : 완료(빠른 순) → 초록 많은 순 → 노랑 많은 순 → 제출 적은 순.

**화면 글자 크기** — 마인크래프트 화면 중앙 글자는 큰 줄과 작은 줄 두 가지 크기뿐이다.
짧은 문구(카운트다운, 탐사 시작·종료, 채점 연출)만 큰 줄에 띄우고, 나머지는 작은 줄 + 핫바 위 한 줄에 나눠 띄운다.

## 5. 명령어

| 명령어 | 설명 |
|---|---|
| `/team <1-5>` | 소속 팀 정하기 |
| `/hint` | 시료 분석 (시료 30개, 팀당 5회) |
| `/answer` | 답안지 열기 |
| `/set` · `/back` | 복귀 지점 저장 · 이동 |
| `/dm <닉네임> <내용>` | 귓속말 (서버 콘솔에 기록) |
| `/health` · `/hungry` | 체력 · 허기 회복 |
| `/pickaxe` (`/tools`) | 곡괭이 · 화석 나침반 · 조사 노트 다시 받기 |
| `/geohelp` (`/gh`) | 명령어 목록 |
| `/start` · `/stop` · `/reset` | (관리자) 시작 · 강제 종료 · 초기화 |
| `/geo setregion <1-5> <색>` | (관리자) 근처 모형을 그 팀 모형으로 등록 |
| `/geo removeregion <1-5>` | (관리자) 등록 해제 |
| `/geo setteam <닉네임> <1-5>` | (관리자) 팀 강제 지정 |
| `/geo wall <1-5\|all> [remove]` | (관리자) 모형 옆면을 벽으로 가리기 · 없애기 |
| `/geo list` · `/geo reload` | (관리자) 등록 현황 · 다시 불러오기 |

관리자(OP)는 **크리에이티브일 때만** 규칙을 무시하고 자유롭게 건축할 수 있다.
서바이벌이면 학생과 같은 규칙이 적용된다 (테스트용).

## 7. 처음 빌드할 때 확인할 것

인터넷이 막힌 환경에서 만들어서 실제 Paper 26.3 로는 컴파일해 보지 못했다
(Paper 구조를 흉내 낸 임시 틀로 문법·로직만 확인). 26.3 에서 이름이 바뀌었을 가능성이 있는 곳:

- `pom.xml` 의 `paper.version` 빌드 번호
- 점수판 숫자 숨김·줄 이름 : `Objective.numberFormat(NumberFormat.blank())`, `Score.customName(...)` (`ui/Scoreboards.java`)
- 조사 노트 : `BookMeta.title/author/addPages` (`item/Items.java`)
- 확정 칸 반짝임 : `ItemMeta.setEnchantmentGlintOverride` (`ui/AnswerGui.java`)
- 화면 중앙 알림 : Adventure `Title.Times.times(...)` (`ui/TitleQueue.java`)
- 블록 부서짐 효과 : `Particle.BLOCK` (`listener/MiningListener.java`)
- 체력 : `Attribute.MAX_HEALTH`, 점프 강화 : `PotionEffectType.JUMP_BOOST` (`game/GameManager.java`)

에러가 나면 Actions 로그의 `[ERROR] ... .java:[줄,칸]` 부분을 그대로 복사해 보내면 된다.

## 8. 베타 테스트 체크리스트

- [ ] `//paste` 후 `/geo setregion` 이 원점을 찾는가, 발광 기둥 색이 맞는가
- [ ] 2×2 캐기 방향(수평·위아래), 웅크리면 1칸, 모형 밖은 안 캐지는가
- [ ] 화면 중앙 글자가 잘리지 않는가 (힌트 결과, 채점 연출, 시료 부족 안내)
- [ ] `/geo wall all` 로 옆면이 가려지고, 벽을 캐고 들어갈 수 있는가
- [ ] 시작하면 점프 강화가 걸리고, 죽었다 살아나도 유지되는가
- [ ] 힌트 : 30개 소모, 부족·잘못된 시료일 때 차감 안 됨, 조사 노트 기록
- [ ] 화석 나침반이 자기 팀 모형의 화석을 가리키는가 (① 얕음 → ④ 깊음), 화석 우클릭 기록
- [ ] 나침반을 좌·우클릭해도 순간이동하지 않는가 (OP 계정으로 확인)
- [ ] 답안지 : 시료 놓기 · 연대 입력 · 비우기 · 비용 · 5초 대기 · 결과 연출
- [ ] 점수판 ▶ 표시, 순위 정렬, 다른 팀 소식
- [ ] `/stop` 자동 채점과 순위 발표, `/reset` 블록 복구
